# Circle Walker 设计文档

## 1. 项目起源

本项目始于一个对“人如何走路”的观察：人走路时不是一次性规划好整条路径，而是每走一步才决定下一步的方向。这种“步态式决策”启发了整个模型的设计。

## 2. 核心问题

传统路径规划方法（如 A*、RRT）通常需要：
- 全局地图
- 预先计算完整路径
- 对动态环境适应较慢

本项目尝试回答：**能否像人走路一样，只凭当前感知，一步步走向目标？**

## 3. 核心概念

### 3.1 绿色圆（Green Circle）
以起点和终点为焦点，通过波前干涉自然生成的动态参考圆。它是每一步决策的“工作台”，小车每次只需要在这个圆上选择一个点作为下一步目标。

### 3.2 虚轴法（Virtual Axis Method）
过绿色圆圆心画一条直线（虚轴），与圆的交点就是候选的下一步目标点。旋转虚轴方向即可改变路径，实现对障碍物的避让。

### 3.3 双频架构（Dual-Frequency Architecture）
- **低频定坐标**：每隔一段距离，重新计算绿色圆（更新参考系）
- **高频寻点**：在同一绿色圆上快速尝试多个方向，选择最优的下一步

### 3.4 步态（Gait）
路径由一系列 M 点逐步生成：
> S → M₁ → M₂ → M₃ → … → E

每一步只走一个 M 点，走完后重新生成绿色圆，再走下一步。

### 3.5 β 参数
虚轴与起点-终点连线的夹角，用于控制“绕路程度”：
- β 小 → 路径更直
- β 大 → 路径更绕

### 3.6 离心率 e
描述椭圆形状的几何指标，用于判断路径是否“太绕”以及是否需要切换规划策略。

## 4. 方法演变

本项目最初考虑了三种几何方法：
- **椭圆法**：以起点和终点为焦点，用椭圆约束路径
- **切线法**：从起点和终点向绿色圆做切线
- **虚轴法**：过圆心旋转直线

经过测试，虚轴法在以下方面表现最优：
- 计算量最低
- 对动态障碍物适应最快
- 路径调整最灵活
- 实现与展示最直观

因此保留虚轴法为核心方法，椭圆法和切线法的思想被内化到 β 参数与虚轴旋转机制中。

## 5. 参数一览

| 参数 | 含义 | 典型范围 |
| --- | --- | --- |
| β | 虚轴与起点-终点连线的夹角 | 15° ~ 75° |
| R | 绿色圆半径 | 动态计算（逐步缩小） |
| Δt | 时间切片间隔 | 0.5 ~ 2.0 秒 |
| θ_step | 角度搜索步长 | 1° ~ 5° |
| 障碍物缓冲区 | 额外安全距离 | 0.2 ~ 0.5 单位 |
| e | 离心率 | 0 ~ 1 |

## 6. 运行逻辑

```

低频（定坐标）：更新绿色圆
↓
高频（寻点）：搜索最优 M 点
↓
小车移动到 M 点
↓
（重复）

```

## 7. 适用范围

- 游戏 NPC 移动
- 无人机路径规划
- 无地图环境下的移动系统
- 多智能体协同场景（扩展中）
