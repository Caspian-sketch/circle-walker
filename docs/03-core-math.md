# 06 - 步态频率与重建频率

## 物理直觉

人走路有天然的节奏——每一步的步长和步频构成了稳定的步态。
这个步态决定了 S 的移动速度，进而决定了波前重建的频率。

**重建频率不是手动设定的参数，而是从运动节奏中推导出来的。**

## 已知量

- L：步长（每步走的距离）
- f_step：步频（每秒步数）
- d：S 到 E 的当前距离

## 推导

### S 的实际移动速度

v_agent = L × f_step

### 重建周期

S 波追上 E 波的条件是 R_S - R_E >= d。
在一次重建之后，R_S 和 R_E 的差值从 0 开始增长。
当差值增长到 d 时，触发下一次重建。

S 在这个过程中实际移动的距离约等于 d。

因此：

重建周期 = d / v_agent

### 重建频率

f_rebuild = 1 / 重建周期 = v_agent / d = (L × f_step) / d

## 关系总结

| 变量 | 对重建频率的影响 |
|------|------------------|
| 步长 L 增大 | 重建频率升高 |
| 步频 f_step 增大 | 重建频率升高 |
| 距离 d 减小（靠近终点） | 重建频率升高 |
| 距离 d 增大（远离终点） | 重建频率降低 |

## 直觉验证

- 离终点远时，抬头看路的频率低——因为参照物还远，不需要频繁校准。
- 离终点近时，抬头看路的频率高——因为参照物切换得快，需要更频繁地确认方向。

## 反向用法

如果希望重建频率保持在一个目标值 f_target，可以反推需要的移动速度：

v_agent = d × f_target

进而调整步长或步频来匹配这个速度。

# 07 - 弧线拟合直线的偏差度量

## 问题

绿色圆在 R_S = R_E 时正对 S-E 连线方向。
当 R_S ≠ R_E 时，绿色圆相对于 S-E 方向有一个微小的偏转。

这个偏转有多大？什么时候该触发重建？

## 几何分析

两个波前圆相交，产生两个交点。这两个交点的连线是公共弦。

以公共弦为直径的圆就是绿色圆。

当 R_S = R_E 时，公共弦垂直于 S-E 连线，绿色圆正对终点方向。
当 R_S ≠ R_E 时，公共弦不再垂直于 S-E 连线，绿色圆歪了。

## 偏差角 δ

定义 δ 为公共弦与 S-E 连线的垂线之间的夹角。

- δ = 0：绿色圆正对终点，拟合最好
- δ 越大：绿色圆歪得越厉害，拟合越差

## 计算 δ

设 S 到 E 的方向角为 θ_SE = atan2(Ey - Sy, Ex - Sx)。

两个交点的坐标可以由两圆方程联立求得。
设两个交点的方向角（从绿色圆圆心 O 看）分别为 φ1 和 φ2。

公共弦的方向角为 (φ1 + φ2) / 2 + π/2。

δ = |公共弦方向角 - (θ_SE + π/2)|

当 δ 超过阈值 δ_max 时，触发波前重建。

## δ_max 的选取

- δ_max 小（如 5°）：拟合要求严格，重建频繁，路径精准
- δ_max 大（如 20°）：拟合要求宽松，重建少，路径平滑

δ_max 是系统对"弧线偏离直线"的容忍度。

# 08 - 步长约束

## 问题

每一步 S 向 M 点移动一个步长。步长取多大才合理？

太大，一步跨出绿色圆，下一轮的参考系完全变了，路径会震荡。
太小，移动太慢，浪费计算。

## 核心约束

步长必须小于当前绿色圆的半径 R。

步长 < R

如果步长 >= R，S 可能一步跨出绿色圆的范围。
下一次计算绿色圆时，S 的位置已经和上一轮的参考系脱节。

## 经验舒适区间

步长 ≈ 0.15R 到 0.25R

- 0.15R：保守，路径平滑，适合密集障碍物
- 0.25R：积极，移动快，适合空旷环境

## R 的动态变化

R 不是常数。它随着 S 移动和波前演化而变化。

- 初始阶段：R 从小变大（两波刚开始相交）
- 中间阶段：R 相对稳定
- 接近终点：R 逐渐缩小（S 靠近 E）

因此步长也应该动态调整：

步长 = k × R，其中 k ∈ [0.15, 0.25]

这样可以保证步长始终与当前绿色圆的大小成比例。

## 与 β 的关系

步长和 β 共同影响路径质量：

- 大步长 + 小 β：走得直但可能震荡
- 小步长 + 大 β：走得稳但可能绕路
- 小步长 + 小 β：精细且直接（理想组合）
- 大步长 + 大 β：粗糙且绕路（应避免）

建议搭配：步长取 0.2R，β 取 30° 到 45°。

# 09 - 收敛性分析

## 问题

Circle-walker 能不能保证到达终点？会不会陷入死循环或发散？

## 前提条件

β < 90°

β 是虚轴偏离目标方向的最大允许角度。
这个条件保证了 M 点始终在"前进半平面"内。

## 前进半平面

以 S 为原点，S-E 连线为基准。
前进半平面是 M 点满足以下条件的区域：

M 到 E 的距离 < S 到 E 的距离

用向量表示：向量 SM 在 SE 方向上的投影为正。

## 单调递减

每一步选取的 M 点满足 β < 90°，因此 M 一定在前进半平面内。

设 d_i 为第 i 步时 S 到 E 的距离。

d_{i+1} = M 到 E 的距离 < S 到 E 的距离 = d_i

因此 {d_i} 是一个严格递减的序列。

## 下界

d_i >= 0（距离非负）

## 收敛

单调递减且有下界的序列必然收敛。

收敛值 d* 满足 d* >= 0。

当 d* < ε（收敛阈值）时，路径结束，智能体到达终点。

## 不收敛的情况

β >= 90° 时，M 点可能落在后退半平面。
此时 d_{i+1} 可能大于 d_i，路径可能绕圈或发散。

**因此 β 必须严格小于 90°。** 建议取值 15° 到 75°。

## 障碍物的影响

障碍物可能阻挡目标方向，迫使虚轴偏转。
但只要 β < 90° 且存在至少一个障碍物投影不覆盖整个允许区间的方向，
M 点仍然落在前进半平面内，收敛性保持不变。

如果障碍物完全封堵了前进方向（U 形障碍物），
需要临时扩大 β 或采用其他策略绕过。

# 10 - 三维扩展

## 物理直觉

人在陆地上走路是二维避障（左绕右绕）。
但在水中游泳或无人机飞行时，障碍物可能在上方或下方，
避障变成三维的。

Circle-walker 的波前干涉模型天然支持三维，
因为两个球面相交自然产生一个空间圆。

## 二维与三维的对应

| 概念 | 二维 | 三维 |
|------|------|------|
| S, E | 平面坐标 (x, y) | 空间坐标 (x, y, z) |
| 波前形状 | 圆 | 球面 |
| 波前半径 | R_S, R_E | R_S, R_E（定义不变） |
| 相交结果 | 两个点 | 一个空间圆 |
| 绿色圆 | 平面圆 | 空间圆（有法向量） |
| 圆心 O | 在 S-E 线段上 | 在 S-E 线段上（公式不变） |
| 虚轴 | 在平面内旋转 | 在空间圆的平面内旋转 |
| 障碍物 | 圆形投影到圆上 | 球形投影到空间圆平面上 |

## 唯一需要修改的公式

S 到 E 的距离 d：

二维：d = sqrt( (Ex - Sx)^2 + (Ey - Sy)^2 )

三维：d = sqrt( (Ex - Sx)^2 + (Ey - Sy)^2 + (Ez - Sz)^2 )

**其余所有公式保持不变。**

- 相交条件：R_S + R_E > d，|R_S - R_E| < d
- 圆心位置：a = (R_S^2 - R_E^2 + d^2) / (2d)
- 绿色圆半径：R = sqrt(R_S^2 - a^2)
- M 点坐标：M = O + R × 方向向量（在空间圆的平面内）

## 绿色圆的方向

三维中，两个球相交产生的空间圆有自己的法向量 n。

n 的方向与 S-E 连线平行。

虚轴在垂直于 n 的平面内旋转。

## 障碍物投影

障碍物是三维空间中的球体（或椭球体）。
将其投影到绿色圆所在的平面上，得到圆形禁区。
投影公式与二维情况一致，只是距离计算使用三维距离。

## 应用场景

- 无人机三维避障飞行
- 水下机器人路径规划
- 太空飞行器交会对接
- 三维游戏 NPC 寻路
